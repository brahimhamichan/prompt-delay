Prompt Later

A Codex hook for sending prompts later.

$ npx prompt-later

Getting started

•Run npx prompt-later, restart Codex, and approve the hook when prompted.

•Use /wait 10s hello, /wait 1.5h queue run tests, or /steer 30 seconds stay concise.

•The hook runs /bin/sleep before Codex calls the model, then forwards only the delayed text as hook context.

FAQ

Does the agent run the wait?

No. The hook runs first, before the prompt is sent to the model.

Does it rewrite the visible prompt?

No. Codex hooks can add context or block. Prompt Later uses context after the wait completes.

Why keep tiny skill files?

They make autocomplete work. Their body is empty and the description tells the model the hook already ran.
